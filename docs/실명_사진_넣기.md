# 실제 이름 · 선수 사진 넣기

PITCH BOSS는 처음에 **지어낸 이름(패러디 이름)** 으로 나옵니다. 사진도 없습니다.
실제 이름과 사진은 **각자 자기 기기에 넣어서** 씁니다.

> 넣은 이름 · 사진은 **내 기기 브라우저 안에만** 저장됩니다. 어디로도 보내지 않습니다.
> 실명 데이터와 사진은 혼자 즐기는 용도로만 쓰고, 다른 사람에게 나눠 주지 마세요.

## 1. 실명 데이터 넣기

**준비물:** 실명 데이터 폴더 하나 (안에 `meta` · `clubs` · `seasons` 폴더가 있는 폴더).
폴더가 없으면 맨 아래 [실명 데이터 폴더 만들기](#실명-데이터-폴더-만들기-pc-고급)를 보세요.

### 첫 화면에서 넣기

1. 첫 화면 메뉴에서 **데이터베이스** 를 누릅니다.
2. **실명 데이터 폴더 고르기** 를 눌러 폴더를 고릅니다. (폴더를 그 칸에 끌어다 놓아도 됩니다.)
3. 브라우저가 "업로드할까요?" 하고 물으면 **업로드** 를 누릅니다. 이름만 '업로드'이고, 실제로는 내 브라우저 안에만 저장됩니다.
4. 다 들어가면 게임이 자동으로 **실명** 으로 바뀝니다.

폴더 안에 `photos` 폴더가 있으면 사진도 함께 들어갑니다.

### 게임하다가 넣기

게임 화면 왼쪽 메뉴의 **실명 데이터** 칸에서 **+ 파일 추가** 를 누르고 폴더를 고르면 됩니다.
지금 하던 게임은 자동 저장되고, 실제 이름으로 바뀌어서 그대로 이어집니다.

### 패러디 이름으로 하던 게임을 실명으로

- 게임 중이면 왼쪽 메뉴 **실명 데이터** 스위치를 켭니다.
- 첫 화면이면 실명 데이터를 켠 뒤 **이어하기** 나 **불러오기** 를 누릅니다. 실명으로 바꿀지 물어봅니다.

⚠ 한 번 실명으로 바꾼 게임은 **패러디 이름으로 되돌릴 수 없습니다.** 원래 게임을 남기고 싶으면 먼저 **저장하기 → 파일로 내보내기** 를 해 두세요.

### 끄기 · 지우기

- **데이터베이스** 의 실명 데이터 스위치를 끄면 다시 패러디 이름으로 플레이합니다.
- **지우기** 를 누르면 브라우저에 넣어 둔 실명 데이터가 빠집니다. 원본 폴더와 세이브는 그대로입니다.

## 2. 이름 직접 바꾸기

실명 데이터 없이 몇 명만 바꾸고 싶을 때 씁니다.

**한 명씩:** 선수 정보 · 구단 창 · 감독 이름 옆의 **✎** 를 누르고 고쳐 씁니다.

**여러 명 한꺼번에 (엑셀):**

1. **데이터베이스 → 내 데이터** 에서 **이름 목록 내려받기** 를 누릅니다.
2. 받은 파일을 엑셀로 열고 **'바꿀 이름'** 칸만 채웁니다. 비워 둔 줄은 그대로입니다.
   - `id` 칸은 절대 고치지 마세요. 게임이 선수를 찾는 번호입니다.
   - `짧은 이름` 은 경기장 위에 보이는 이름입니다. 비우면 이름의 마지막 단어를 씁니다.
3. 그냥 저장한 뒤 **고친 목록 올리기** 로 그 파일을 고릅니다.

## 3. 사진 넣기

**한 명씩 (휴대폰도 됨):**

1. 선수 정보를 엽니다.
2. 사진 칸을 누릅니다. 사진이 없으면 **+ 사진** 이 보입니다.
3. **사진 고르기** 를 눌러 사진을 고르고, 끌어서 얼굴 위치를 맞춥니다.

**여러 장 한꺼번에:**

1. 사진 **파일 이름** 을 아래처럼 바꿉니다.

   | 파일 이름 | 뜻 |
   |---|---|
   | `p00000a1.jpg` | 선수 번호 (가장 정확. 번호는 이름 목록 파일의 `id` 칸) |
   | `모하메드 살라흐.jpg` | 게임에 보이는 이름 그대로 (같은 이름이 여럿이면 건너뜀) |
   | `p00000a1_2017-18.jpg` | 그 시즌에만 쓰는 사진 |

2. **데이터베이스 → 내 데이터** 에서 **사진 여러 장 고르기** 를 누르고 사진을 한꺼번에 고릅니다.

jpg · png · webp 를 쓸 수 있습니다. 얼굴 쪽으로 알아서 잘라 주고, 나중에 사진 칸에서 다시 맞출 수 있습니다.

**사진 숨기기:** **데이터베이스** 의 선수 사진 스위치를 끄면 사진이 안 보입니다. 넣은 사진은 지워지지 않습니다.

---

## 4. 휴대폰으로 옮기기

PC에서 넣은 이름 · 사진(원하면 실명 데이터까지)을 파일 하나로 옮깁니다.

1. PC: **데이터베이스 → 내 데이터** 에서 **내 데이터 내보내기** 를 누릅니다.
   실명 데이터도 옮기려면 **실명 데이터도 함께** 를 체크합니다.
2. 나온 `.pitchboss` 파일을 휴대폰으로 보냅니다 (메신저, 클라우드 등).
3. 휴대폰: 같은 화면에서 **가져오기** 를 누르고 그 파일을 고릅니다.

## 자주 묻는 질문

**정말 어디로도 안 보내나요?**
네. 모두 그 기기의 브라우저 안에만 저장됩니다. 브라우저 데이터를 지우면 같이 지워집니다.

**브라우저나 기기를 바꾸면요?**
새로 넣어야 합니다. [4. 휴대폰으로 옮기기](#4-휴대폰으로-옮기기) 의 파일 하나로 옮기면 편합니다.

**넣었는데 이름이 그대로예요.**
**데이터베이스** 에서 실명 데이터 스위치가 켜져 있는지 보세요. 패러디 이름으로 시작한 게임이면 [실명으로 바꾸기](#패러디-이름으로-하던-게임을-실명으로) 를 해야 합니다.

**"실명 데이터를 찾지 못했습니다" 라고 나와요.**
`meta` · `clubs` · `seasons` 가 **바로 안에 들어 있는 폴더** 를 골랐는지 확인하세요. 그 위 폴더를 골라도 대부분 찾지만, 엉뚱한 폴더면 못 찾습니다.

## 실명 데이터 폴더 만들기 (PC, 고급)

실명 데이터는 공개 자료(Wikidata · 위키백과)에서 **각자 PC에서 직접 만듭니다.**
[Node.js](https://nodejs.org) 와 이 저장소가 필요하고, 리그 하나에 1시간쯤 걸립니다.

```bash
node tools/data_pipeline build --league eng1 --apply     # 리그 만들기 (eng1 대신 esp1 ita1 ger1 fra1, 2부는 eng2 …)
node tools/data_pipeline names --league eng1 --apply     # 한국어 이름
node tools/validate.js                                   # 검사 ("오류 없음" 이면 끝)
```

다 만들면 저장소의 `data` 폴더가 실명 데이터 폴더입니다. 이 폴더를 [1. 실명 데이터 넣기](#1-실명-데이터-넣기) 로 넣으면 됩니다.
(개발 서버 `npm run dev` 로 직접 실행하면 따로 넣지 않아도 자동으로 씁니다.)

**사진을 PC에서 한꺼번에 모으려면** (개발 서버로 실행할 때):

```bash
cd tools && npm install && cd ..                          # 처음 한 번 (얼굴 찾기 도구)
node tools/data_pipeline photos-ids --club liverpool      # 그 구단 선수 번호 목록 (CSV)
# 사진을 data/photos/inbox/선수번호/2025-26.jpg 처럼 넣은 뒤
node tools/data_pipeline photos-import                    # 얼굴 위치를 맞춰 넣기
```

이렇게 만든 `data/photos` 폴더는 **데이터베이스 → 내 데이터 → PC 사진 폴더 고르기** 로 다른 브라우저에도 넣을 수 있습니다.
